## 1. Мета та межі робіт

Розробити україномовний адаптивний інформаційний сайт про археологію світу з редакційною системою керування матеріалами. Редакція веде сайт самостійно, без участі розробника.

**Роль макетів.** Макети — лише референс стилю: кольори, типографіка, щільність верстки, загальне враження. Склад, кількість і порядок блоків, назви рубрик і функції визначає це ТЗ. Якщо макет і ТЗ розходяться, діє ТЗ. Тексти, цифри, імена й фото на макетах — заглушки, їх не переносять на сайт.

**Стиль.** Газетна композиція, насичений темно-синій верхній блок, білий фон, блакитні заголовки секцій, виразна типографіка, щільна новинна верстка.

**Входить у роботи:** дизайн усіх шаблонів з цього ТЗ, верстка для трьох типів екранів, CMS, SEO-база, аналітика, запуск на хостингу, навчання редакції. **Не входить** без окремого погодження: написання матеріалів, багатомовність, мобільний застосунок, платна підписка.

## 2. Навігація та класифікація

Кожен матеріал має тип, географічну рубрику, хронологічну рубрику та довільні теги.

- **Основне меню:** Новини; Публікації; Колонки; Інтерв’ю; Спецпроєкти; Архів.
- **Службове меню:** Про проєкт; Команда; Партнери; Підтримати. Плюс пошук, посилання на соцмережі, мобільне меню.
- **Географічні рубрики (рівно 6, у цьому порядку):** Європа; Азія; Африка; Північна Америка; Південна Америка; Австралія та Океанія.
- **Хронологічні рубрики (рівно 12, у цьому порядку):** Палеоліт; Мезоліт; Неоліт; Енеоліт; Бронзова доба; Залізна доба; Античність; Середньовіччя; Ранньомодерна доба; Індустріальна доба; XX століття; Сучасність.
- **Типи матеріалів:** новина, публікація, колонка, інтерв’ю, спецпроєкт, партнерський матеріал.

Матеріал може мати кілька географічних і хронологічних рубрик. Одна в кожній групі позначається як основна; без основної рубрики матеріал не публікується. Основні рубрики йдуть у хлібні крихти й розмітку; додаткові показуються посиланнями поруч із тегами, а матеріал виводиться в усіх своїх рубриках.

Списки рубрик редагуються в адмінпанелі без розробника (назва, порядок, опис, SEO-поля).

## 3. Структура URL і хлібні крихти

URL не залежать від рубрик, тому зміна рубрики не ламає посилань. Адреси — латиницею, транслітерація за офіційною українською системою, нижній регістр, дефіси.

| Сторінка | Шаблон URL | Приклад |
| --- | --- | --- |
| Матеріал будь-якого типу | `/<тип>/<slug>/` | `/novyny/stounkhendzh-novi-dani/` |
| Тип матеріалів | `/<тип>/` | `/publikatsii/` |
| Регіон | `/region/<slug>/` | `/region/yevropa/` |
| Епоха | `/epokha/<slug>/` | `/epokha/neolit/` |
| Регіон + епоха (фільтр) | `/region/<slug>/?epokha=<slug>` | `/region/yevropa/?epokha=neolit` |
| Тег | `/teh/<slug>/` | `/teh/meghality/` |
| Автор | `/avtor/<slug>/` | `/avtor/ivan-petrenko/` |
| Архів за датою | `/arkhiv/<рік>/<місяць>/` | `/arkhiv/2026/11/` |
| Пошук | `/poshuk/?q=<запит>` | — |

- Сторінки з фільтрами, пошуку та пагінації вище другої мають `noindex, follow` або canonical на основну сторінку — фінальне правило затверджує SEO-спеціаліст.
- Slug генерується з заголовка автоматично й редагується вручну. При зміні slug після публікації автоматично створюється редирект 301.

**Хлібні крихти матеріалу:** Головна › Тип › Основний регіон › Основна епоха. Кожен елемент — посилання, заголовок матеріалу в крихти не входить. Дублюються в розмітці BreadcrumbList.

## 4. Шаблон головної сторінки

**Шапка (спільна для всіх сторінок):** службове меню; логотип «МІДГАРД»; підпис «ЗАГУБЛЕНИЙ СВІТ ЛЮДЕЙ»; головне меню; пошук; два горизонтальні рядки «Регіони світу» (6) та «Епохи» (12).

| 1, ліва колонка | Останні новини | 10–15 (налаштовується) | час, заголовок; внизу «Усі новини →» | автоматично, за часом публікації |
| 1, центр | Текст дня | 1 | велике фото, заголовок, короткий опис, дата, автор | редактор обирає вручну |
| 1, права колонка | Головне сьогодні | 10–15 (налаштовується) | мініатюра, заголовок | редактор обирає і сортує вручну |
| 2, ліва | Публікації | 5 | мініатюра, заголовок | останні або закріплені редактором |

- Банер із логотипами партнерів замість розділу «Партнерські матеріали» не використовується.

## 5. Шаблон сторінки матеріалу

Сторінка матеріалу має спільну шапку, основну колонку та праву колонку. Один шаблон працює для всіх типів; відмінності перелічені нижче.

**Основна колонка, згори вниз:**

1. Хлібні крихти (розділ 3).
2. H1 — заголовок.
3. Підзаголовок / анотація.
4. Дата й час публікації; дата оновлення, якщо матеріал суттєво змінювали.
5. Автор з посиланням на сторінку автора (за наявності; для новин можна «Редакція»).
6. Кнопки поширення: Facebook, Telegram, X, копіювання посилання. Без сторонніх віджетів, що гальмують завантаження.
7. Головне фото з підписом і кредитом (автор / джерело / ліцензія).
8. Текст. Підтримує: H2/H3, фото, фотогалереї, відео (YouTube та власне), цитати, виноски, таблиці, карти, внутрішні посилання, вставки постів соцмереж. Заголовки на кшталт «Деталі» чи «Чому це важливо» необов'язкові.
9. Блок «Джерело»: одне або кілька джерел з посиланнями. Обов'язковий для новин.
10. Теги та додаткові рубрики.
11. «Читайте також» — 4 матеріали: вручну від редактора, інакше автоматично за спільними тегами та рубриками.

**Права колонка:** «Останні новини» — щонайменше 5 позицій і «Усі новини →»; «Популярні» — 5 матеріалів з мініатюрами. Популярність береться з реальної аналітики або з ручного добору. Лічильники переглядів показуються лише тоді, коли цифри справжні (вмикається в адмінці, за замовчуванням вимкнено).

**Відмінності за типами:**

| Тип | Що додається або змінюється |
| --- | --- |
| Колонка | фото та короткий опис автора вгорі; позначка «Думка автора може не збігатися з позицією редакції» |
| Інтерв’ю | картка співрозмовника (фото, ім'я, посада / науковий ступінь); формат «питання — відповідь» з візуально виділеними питаннями; автор інтерв’ю |
| Спецпроєкт | повноширинна обкладинка без правої колонки; може мати кілька частин із змістом |
| Партнерський матеріал | позначка «Реклама» біля заголовка та назва замовника; зовнішні посилання з `rel="sponsored"`; не потрапляє в «Популярні» і news-sitemap |

## 7. Редакційна система (CMS)

Редакція виконує всі повсякденні дії в адмінпанелі без розробника і без редагування HTML.

**Матеріали:** створення, редагування, чернетки, попередній перегляд, відкладена публікація, зняття з публікації, історія версій з можливістю відкоту, блокування матеріалу, який редагує інша людина. Поля матеріалу — за розділами 2 і 5.

**Ролі:**

| Роль | Може |
| --- | --- |
| Адміністратор | усе, включно з користувачами, рубриками, налаштуваннями, редиректами |
| Редактор | редагувати й публікувати будь-які матеріали, керувати головною та тегами |
| Автор | створювати й редагувати власні чернетки, надсилати на перевірку; без права публікації |

**Головна сторінка:** вибір «Тексту дня»; додавання, видалення й перетягування позицій у «Головному сьогодні»; закріплення матеріалів у блоках другого рівня; кількість позицій у бічних стрічках (10–15). Стрічка «Останні новини» заповнюється автоматично.

**Медіатека:** завантаження фото, обов'язкові поля alt і кредит, підпис, ліцензія; автоматичні розміри та WebP/AVIF; кадрування під мініатюри й OG-зображення; пошук по медіатеці.

**Службове:** редагування рубрик, тегів (злиття дублів), профілів авторів, статичних сторінок, меню та футера; список редиректів 301; журнал дій користувачів.

**Реклама й аналітика:** місця під рекламні блоки вимикаються в адмінці та не зсувають верстку при завантаженні; підключення Google Analytics 4 або іншої системи та Google Search Console; дані для «Популярних» — з цієї аналітики.

## 8. SEO, Google News / Discover, RSS

Усе нижче працює автоматично з першого дня, на всіх шаблонах.

**База:**

- Редаговані title і description для матеріалів, рубрик, тегів, авторів; якщо не заповнені — беруться із заголовка й анотації.
- ЧПУ-адреси (розділ 3), canonical, редиректи 301, код 404 для неіснуючих адрес.
- sitemap.xml (з автооновленням), robots.txt (редагується в адмінці).
- Open Graph і Twitter Card з окремим OG-зображенням 1200×630.
- Розмітка schema.org: NewsArticle для новин, Article для інших типів, BreadcrumbList, Person для авторів, NewsMediaOrganization для сайту. Дати публікації й оновлення — з часовим поясом.
- Мова сайту в розмітці: `lang="uk"`.

**Google News і Discover:**

- Окремий news-sitemap з матеріалами за останні 2 дні (без партнерських).
- Метатег `max-image-preview:large`.
- Головне фото матеріалу — щонайменше 1200 пікселів за шириною; CMS попереджає, якщо фото менше.
- Сторінки авторів, «Про проєкт», «Контакти» і редакційна політика доступні з футера на кожній сторінці.

**RSS:** загальна стрічка та окремі стрічки для кожного типу, регіону та епохи. У стрічці: заголовок, анотація, посилання, дата, автор, головне фото.

## 9. Адаптивність, швидкість, доступність

Сайт приймається за вимірюваними цілями з таблиці, а не за враженням.

**Адаптивність.** Телефон (від 360 px), планшет (від 768 px), десктоп (від 1280 px). На телефоні:

- компактна шапка з меню-бургером і пошуком;
- регіони та епохи — горизонтальна прокрутка або розгортання;
- порядок блоків головної: Текст дня → Останні новини → Головне сьогодні → Публікації → Колонки → Спецпроєкти → Партнерські матеріали; жоден блок не приховується;
- на сторінці матеріалу права колонка переходить під текст, після «Читайте також».

**Цілі приймання:**

| Показник | Ціль | Як перевіряється |
| --- | --- | --- |
| LCP (завантаження головного елемента) | ≤ 2,5 с | PageSpeed Insights, мобільний режим, головна й матеріал |
| INP (відгук на дії) | ≤ 200 мс | те саме |
| CLS (зсув верстки) | ≤ 0,1 | те саме, з увімкненими рекламними блоками |
| Lighthouse Performance, мобільний | ≥ 85 | Lighthouse |
| Lighthouse Accessibility | ≥ 95 | Lighthouse |
| Доступність | WCAG 2.1, рівень AA | вибіркова ручна перевірка: клавіатура, контраст, alt, заголовки |

**Технічні вимоги:** WebP/AVIF з фолбеком, `srcset` для кожного зображення, lazy loading усього нижче першого екрана, кешування сторінок і CDN для статики, власні шрифти з `font-display: swap` і кирилицею. Браузери: останні 2 версії Chrome, Safari (включно з iOS), Firefox, Edge.

## 10. Безпека, реклама, права на зображення

**Безпека:**

- HTTPS на всіх сторінках, редирект з HTTP і www на одну основну адресу.
- Адмінпанель: двофакторна автентифікація, обмеження спроб входу, нестандартна адреса входу.
- Форми захищені від спаму.
- Автоматичні резервні копії бази й медіа щодня, зберігання щонайменше 30 днів, копія поза сервером сайту. Відновлення з копії перевіряється перед здачею.
- Оновлення CMS і додатків без втрати налаштувань; журнал змін.
- Моніторинг доступності сайту зі сповіщенням про падіння.

**Права на зображення.** Редакція відповідає за ліцензії. CMS не дає опублікувати фото без заповнених полів «автор / джерело» і «ліцензія». Розробник для демо й тестування використовує лише вільні зображення або надані редакцією та прибирає всі тестові дані перед запуском.

**Персональні дані.** Аналітичні й рекламні скрипти запускаються лише після згоди в cookie-банері. Дані з форм доступні лише адміністраторам.
