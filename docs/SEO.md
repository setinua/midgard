# Правила метаданих «Мідгарду»

Погоджено власником 28.11.2026. Код правил — `src/lib/seo.ts`.

## Як працює

Поле «SEO» в адмінці (SEO-заголовок і SEO-опис) завжди має перевагу. Якщо воно порожнє, сайт бере шаблон свого типу сторінки.
Під полями є лічильник символів: це підказка, а не заборона.

## Загальні правила

1. Title — до 60 символів разом із брендом. « | Мідгард» додається лише тоді, коли влазить. Головне слово запиту — на початку.
2. Description — 120–155 символів, закінчене речення. Анотація обрізається по цілому реченню.
3. H1 — видимий заголовок. Title може бути коротшим і точнішим під пошук, але про те саме.
4. Canonical — на кожній сторінці. Сторінки 2+ і фільтри — noindex, follow.
5. Open Graph на всіх сторінках: title, description, url, site_name, locale uk_UA і картинка JPEG 1200×630. Немає фото — `public/og-default.jpg`.
6. Епоха, регіон чи тег, де менше 3 матеріалів, отримують noindex і не потрапляють у мапу сайту.
7. Партнерські матеріали: зовнішні посилання в тексті — `rel="sponsored"`, в описі — «Партнерський матеріал.».

## Шаблони

| Тип | Title | Description |
|---|---|---|
| Головна | Мідгард — новини археології України та світу | Налаштування → Опис сайту (або стандартний текст) |
| Розділ | Пошукова назва з `SECTION_TITLES` + бренд | Опис із «Налаштування → Розділи» |
| Епоха | «{Епоха}: археологічні відкриття і новини» | Опис епохи або «{Епоха} ({межі}): новини археології…» |
| Регіон | «Археологія {Європи}: новини і відкриття» | Опис регіону або «Археологічні відкриття {в Європі}…» |
| Тег | «{Тег}: новини та статті» | «Усе про тему «{тег}»…» |
| Стаття | SEO-заголовок або заголовок | SEO-опис або анотація, обрізана по реченню |
| Автор | «{Ім’я} — {спеціалізація}» | Біографія |
| Службова | Назва сторінки | Вступ сторінки; «Політика конфіденційності» — noindex |

## Для редакції

- **Новина:** до 55 символів, «де + що знайшли або з’ясували + епоха чи вік». Наприклад: «Мамонт з Баварії: сліди обробки 25 тисяч років тому».
- **Інтерв’ю:** «{Ім’я}: {тема}». Наприклад: «Массімо Осанна: інтерв’ю з археологом Помпеїв».
- **Опис:** хто (археологи, дослідники), що знайшли, де, коли — 120–155 символів.
- **Теги:** 2–5 на статтю — культури, пам’ятки, країни, методи.
